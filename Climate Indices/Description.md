Climate indices in NetCDF file

The following code computes climate indices (Indicators) based Xclim pyhton libray Reference : https://xclim.readthedocs.io/en/stable/indicators.html

Climate indicators Include

Cold indices:- Spring Start, Cold spell, Cold spell duration Index, frost days, frost seasonal length, ice days
Precipitation indices: Wet days RR1mm,CWD, liquid precipitation ratio (LPR), Total Precipitation, cold_wet days, Standard precipitation indice SPI-3-6
Extreme precipitation indices:- Rx1, Rx5, RR10mm, RR20mm, R95p, R99p

Statistical Significant test
- Student_T test
- Modififed  Mann Kendal trend
